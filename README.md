# K线乐章

将股票与指数行情转译为旋律的金融数据听觉化实验。

当前版本已完成前端工作台、FastAPI 行情服务、真实 API 联调和结构化音乐生成 MVP。系统先从真实股票或指数行情提取趋势、波动、成交量和关键转折，再经过曲式、和声、节奏与主题规划生成乐章，通过 Tone.js 播放并导出标准 MIDI 文件。

## 本地运行

### Windows 一键启动

首次准备好 `.env` 后，双击仓库根目录的 `启动K线乐章.cmd`。脚本会检查并安装缺失依赖、启动前后端、等待健康检查通过，然后自动打开页面。

需要关闭后台服务时，双击 `停止K线乐章.cmd`。运行日志保存在 `.run/logs/`，该目录不会提交到 Git。

### 前端

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。

前端默认请求 `http://127.0.0.1:8000`。需要脱离后端演示时，在本地 `.env` 中设置：

```text
VITE_USE_MOCK_API=true
```

### 后端

```powershell
Copy-Item .env.example .env
# 在 .env 中填写本机 MYSQL_PASSWORD
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

接口文档位于 `http://127.0.0.1:8000/docs`。后端详细说明见 [backend/README.md](./backend/README.md)。

## 已实现

- OLED 深色金融音乐工作台；
- Mock K 线、成交量、RSI、MACD；
- 异步 Mock API 与正式 TypeScript 领域类型；
- 可搜索的股票/指数选择器，支持同代码不同市场标的；
- 日期范围选择并同步更新乐章上下文；
- FastAPI、CORS、统一错误响应与健康检查；
- 股票和指数统一的 MySQL 只读 Repository；
- 真实标的搜索与日线范围查询接口；
- MA、RSI、MACD、ATR、波动率与趋势状态；
- 前端真实 API 客户端、请求取消、加载和错误反馈；
- 旋律谱线、钢琴卷帘和钢琴键盘；
- 播放、暂停、进度跳转和音量控件；
- K 线、音符与市场动机同步高亮；
- 收益率到主题轮廓、相对成交量到力度、ATR/波动率到节奏密度的确定性映射；
- 固定 4/4 小节网格、强弱拍、切分节奏、旋律休止与乐句末长音；
- A–A′–B–A″ 曲式，主题重复、变奏、倒影及 B 段音区对比；
- B 段切换同主音大小调并加密和声节奏，形成明确的调式与织体对比；
- 和声逐小节规划，通过共同音保持、最近转位和风格化节奏完成声部进行；
- A/A′ 使用半终止、B 使用伪终止、最终 A″ 使用 V→I 正格终止；
- 趋势自动选择大小调，低活跃 K 线形成休止，关键转折形成重音和长音；
- 乐章生成、查询与 MIDI 下载 API；
- 自动生成结构化主旋律、小节和声与根音/五度低音三条轨道；
- 支持交响乐、氛围钢琴、电子合成、Lo-fi、轻爵士、史诗影视风、国风新民乐、极简氛围和摇滚律动；
- 不同风格会改变节奏密度、和声织体、低音型、旋律跳进、力度、和弦结构、推荐编制及浏览器音色；
- Jazz/Lo-fi 使用摇摆反拍，Jazz 使用 walking bass，Ambient 使用踏板低音，Rock 使用根音—五度—八度低音；
- 摇滚风格额外生成鼓轨，并在段首加入 crash、段尾加入 tom fill；
- Cinematic 段首加入 crash，国风和声使用五声音阶分解织体；
- 最终 A″ 使用整小节主音、持续和弦与踏板低音完成尾奏收束；
- Tone.js 采样钢琴、空间混响、2.8 秒钢琴踏板式释放、弦乐铺底与低音分层播放，采样不可用时自动使用柔和包络降级；
- 播放、暂停、进度跳转、音量和播放结束状态；
- K 线、音符、钢琴键、市场动机使用统一播放时间同步；
- 1680/1440 桌面布局及移动端底部导航；
- 键盘焦点、可访问名称和减弱动效支持。

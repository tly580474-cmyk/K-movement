# K线乐章

将股票与指数行情转译为旋律的金融数据听觉化实验。

当前版本已完成前端工作台、FastAPI 行情服务、真实 API 联调和音乐生成 MVP。系统可将真实股票或指数行情确定性映射为音符，通过 Tone.js 播放并导出标准 MIDI 文件。

## 本地运行

### 前端

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。

前端默认请求 `http://127.0.0.1:8000`。需要脱离后端演示时，在本地 `.env` 中设置：

```text
VITE_USE_MOCK_API=true
```

### 后端

```powershell
Copy-Item .env.example .env
# 在 .env 中填写本机 MYSQL_PASSWORD
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

接口文档位于 `http://127.0.0.1:8000/docs`。后端详细说明见 [backend/README.md](./backend/README.md)。

## 已实现

- OLED 深色金融音乐工作台；
- Mock K 线、成交量、RSI、MACD；
- 异步 Mock API 与正式 TypeScript 领域类型；
- 可搜索的股票/指数选择器，支持同代码不同市场标的；
- 日期范围选择并同步更新乐章上下文；
- FastAPI、CORS、统一错误响应与健康检查；
- 股票和指数统一的 MySQL 只读 Repository；
- 真实标的搜索与日线范围查询接口；
- MA、RSI、MACD、ATR、波动率与趋势状态；
- 前端真实 API 客户端、请求取消、加载和错误反馈；
- 旋律谱线、钢琴卷帘和钢琴键盘；
- 播放、暂停、进度跳转和音量控件；
- K 线、音符与市场动机同步高亮；
- 收益率到音高、相对成交量到力度、ATR 到时值/密度的确定性映射；
- 音阶吸附、C3–C6 音域限制、节拍量化与异常值截断；
- 乐章生成、查询与 MIDI 下载 API；
- 自动生成主旋律、三和弦和声与根音/五度低音三条轨道；
- 默认以约半拍间隔压缩行情时间轴，并使用重叠时值和级进约束形成连贯乐句；
- Tone.js 采样钢琴、弦乐铺底与低音分层播放，采样不可用时自动降级；
- 播放、暂停、进度跳转、音量和播放结束状态；
- K 线、音符、钢琴键、市场动机使用统一播放时间同步；
- 1680/1440 桌面布局及移动端底部导航；
- 键盘焦点、可访问名称和减弱动效支持。

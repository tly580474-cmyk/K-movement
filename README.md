# K线乐章

将股票与指数行情转译为旋律的金融数据听觉化实验。

当前版本是前端驱动开发的第一阶段成果：使用 Mock 数据完成桌面工作台样式、响应式布局和播放器交互，尚未连接 MySQL，也未生成真实 MIDI。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。

## 质量检查

```bash
npm run typecheck
npm run build
```

## 已实现

- OLED 深色金融音乐工作台；
- Mock K 线、成交量、RSI、MACD；
- 异步 Mock API 与正式 TypeScript 领域类型；
- 可搜索的股票/指数选择器，支持同代码不同市场标的；
- 日期范围选择并同步更新乐章上下文；
- 旋律谱线、钢琴卷帘和钢琴键盘；
- 播放、暂停、进度跳转和音量控件；
- K 线、音符与市场动机同步高亮；
- 音乐生成参数和模拟重新生成状态；
- 1680/1440 桌面布局及移动端底部导航；
- 键盘焦点、可访问名称和减弱动效支持。
